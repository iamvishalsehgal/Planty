### Skills to Know About
- **/graphify** — converts any input into a knowledge graph. Used for mapping domain concepts, code structure, or research into linked nodes.
- **/llm-council** — spawns 3-5 domain-expert agents from the 207-agent library in parallel, chairman synthesizes a verdict. Every substantive question goes through council automatically per CLAUDE.md.
- **/clear** — resets conversation context. Used before starting a fresh task to keep the context window lean.
- **/effort** — sets session effort level (e.g. `ultracode` for exhaustive multi-agent work). Use when a task warrants going deep.
- **/model** — switches the underlying Claude model mid-session. Handy for trying a different model on a stubborn problem.
